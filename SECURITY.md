# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it **privately** using GitHub's Security Advisories feature.

### How to Report Privately

1. Click the **Security** tab at the top of this repository
2. Click **Advisories** (on the left sidebar)
3. Click **Report a vulnerability**
4. Fill in the details and submit

This keeps the vulnerability private until we can fix it.

## Why Private Reporting?

We handle security vulnerabilities responsibly by:
- Keeping reports private until a fix is available
- Coordinating a disclosure timeline with you
- Publishing security updates without publicly exposing the vulnerability first

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

Thank you for helping keep this project secure!
